sc-core owns canonical declarations and defines DesignMetadataHost. Higher crates implement the port
using their actual immutable metadata. DesignMetadata owns that host and an identity-only census;
it stores no borrowed context, cloned scalar declaration, numeric value or uncertainty state. Shared
access supplies no mutable host. Each real implementation must preserve a stable immutable snapshot,
complete authored ownership census and exact bindings, and invoke its actual current validators.
This is a trusted integration contract: core cannot independently prove arbitrary provider semantics.

Core checks duplicate metadata identities, canonical-input disjointness and observable census changes.
A measurement query validates the whole metadata scope, checks the requested metadata role, asks the
host for its explicit binding, and requires pointer membership in the supplied dedicated canonical
length inventory. Equal identity/content on a detached declaration is insufficient. That guard proves
object membership; semantic correctness of the metadata-to-target relation belongs to the actual host
implementation. Canonical replacement triggers current validation, without remembered success.

MeasurementInputs now implements the port using actual owned records and original validators.
Full Design assembly and remaining cross-component identity scopes retain their task children.
Logical profile refs
and evaluation context pins keep their G4 deferrals even if canonical numeric ids happen to coincide.
No lookup through a label, fallback value, profile selection, readiness or execution follows admission.

Focused public native and compile-fail contracts exercise observable guards. Broader feature and
integration verification remains with G1's existing owners. The ownership decision is durable now;
subsequent implementation must record its narrower actual acceptance scope in the task tree/book.

Common SizeSetMetadata now owns membership/axes/break metadata separately from canonical inputs and
measurement/Ease sources. Its higher-ranked callback reconstructs temporary actual contexts, checks
all source identities/current validators before invocation and prevents borrowed contexts escaping.
GarmentSizeSet and MtmSizeSet now own actual chart-family sources over that common component.
SizeSetInventory now owns explicit family sources with whole-current exact-reference checks.
DesignSources now owns actual measurement/set metadata, exposing its complete typed core catalog.
The DesignSizeSetHost facet delegates exact external pins to the actual current inventory; numeric
identity presence supplies no replacement metadata. Core remains independent of higher schemas.
Full Design composition follows; the common component alone is not a complete SizeSet, and Design
still holds an external reference. Physical Profile resolution remains G4.

DesignInputs now owns implemented core structure/parameters/recipe/Materials and checked higher
metadata over the structure's single canonical inventory. Complete cross-component ownership ids
precede actual current parameter/Material/Piece/source validation. This is an input composition,
not full Design sewing/garment/readiness proof. Selected input names are checked separately.

DesignSourceReferences now stores explicit Option table/Ease/set refs without Default or inferred
companions. None means unprovided draft input; every Some must resolve in the actual current source
inventory. DesignReferenceHost checks provided-role presence and table/Ease/SizeSet joins; an MTM
chart retains its exact Ease-set identity. DesignInputs owns the unchanged carrier and preserves
original host causes. Validation does not populate missing fields or certify complete readiness.

DesignFormulaHost borrows declarations only from actually selected table/Ease metadata after full
current reference and binding validation. DesignInputs.formula_namespace adds actual parameters,
then delegates to the existing flat namespace for reserved and cross-origin collision checks.
Unknown/Derived data is never evaluated or copied. Local context lifetimes remain local; selected
Ease bindings are validated before borrowing their saved target from the sole canonical owner.
Namespace errors retain borrowed original declarations; static current-input error chains remain
available separately. Unselected metadata and human labels contribute no names. Profile/Material/
geometry inputs, recipe proofs and execution retain their existing separate contracts.

## Actual construction intake roles — G1-SLICE.6.4.5.4.e.1

The intake query validates the whole current root even with empty families, then borrows each actual
Dart/Tuck/Pleat's intake and closing-operation fields in original family/authored order. Views retain
actual distinct objects, original positions and one canonical owner. Formula intake requires actual
Design parameter/current Length metadata; dedicated/general Length and Unknown/Derived remain their
original representations/states. Explicit zero/id/value remain inline intent; logical Profile and
operation ids never coerce to numeric roles. Errors retain actual construction/position/role with
original current-root causes and no partial collection. Current garment sources, operation checks,
global ids, resolved nonnegativity/conservation and physical/release proof remain separate.

## Grain and allowance metadata — G1-SLICE.6.4.5.4.e.2

Whole-current-root validation precedes original grain alignment and allowance width/inclusion roles,
even empty. Common contextual metadata lookup requires actual Design parameter/canonical Angle or
Length kind; it reads no value/state and never converts representations. Parallel alignment borrows
its axis without synthesizing an angle. Explicit zero/angle and Profile references remain actual
fields; mandatory inclusion stays logical despite numeric aliases. Actual objects retain directed
print/corner intent. Current sources, global ids, resolved domains/policies and physical/release proof
remain separate. Original intake/closing behavior is retained through the shared lookup.

## Joined actual Gather declarations — G1-SLICE.6.4.5.4.e.3

construction source families even without Gathers. Each view borrows the original Gather, authored

field. One canonical owner remains; no distribution/value/state or negated intake is copied. Same-Piece

intake/conservation and physical/release proof remain later obligations.

## Exact garment ownership — G1-SLICE.6.4.5.5.a

DesignGarment owns the actual DesignSewing plus six garment inventories, with one canonical owner.
Its deterministic census visits sewing, Pockets, notion placements, Closure/instances, distinct layers,

remain owned; referenced ids stay uses. Global collision witnesses precede current whole-root input

born objects. Complete current garment sources/declarations, execution envelope, physical values and

## Complete current garment sources — G1-SLICE.6.4.5.5.b

Current validation rechecks global ownership/inputs, sewing, Pockets, notions, Closures, layers and
actual Material assignments, Hems, then constructions. Existing validators retain all unused/empty
context obligations, original identity locations/raw repairs and concrete standard causes. Missing
Material targets cannot coerce from numeric metadata; layer sources precede assignment checks.

## Lining modelling differs from Fly birth refusal — D276

Lining::new can retain structural modelled content; its requested-execution scope remains env_lining/
G7. Closure::new instead invokes definition.require_in_scope before instance/domain/target checks:
Fly returns original OutsideEnvelope/FlyDeferred with closure/trousers-gap ids, env_fly and G7 before
an immutable Closure exists, even with no instances or invalid source context. Thus safe public APIs
cannot admit modelled Fly into DesignGarment. Unsupported Fly definitions remain inspectable request
input. D276 corrects newly introduced grouped Lining/Fly Rustdoc/book wording; constructor behavior
and all original refusal priority remain unchanged.

## Explicit requested garment envelope — G1-SLICE.6.4.5.5.d.2

Root require_in_scope checks original authored Closure definitions then complete original layer scope
before execution, without host/source/metadata/geometry validation. Lining retains env_lining/G7,
actual layer/family/index/served Piece and original concrete causes even with damaged sources.
Fly stays pre-birth env_fly/G7 at Closure::new; no immutable Fly is modelled. Scope success proves no
currentness, logical domains/operations, physical support, completeness or release. Inspection and
current declarations stay independently available; no supported replacement is supplied.
