## Goal

One real garment — the reference skirt specified at `G0-CONTRACT.13` — goes from command script
to **dimensionally correct, canonical, printed-and-measured** artifacts, through the same command
bus a UI or an agent would use, with the offset engine proven against a pathology corpus and the
whole pipeline proven deterministic.

G2 is where "implementing an exporter" and "proving its compatibility" are told apart: the exit
is evidence (goldens, pathology corpus, mutation tests, a ruler on paper, an independent agent
session), not a feature list.

## Entry criteria

- `G1-SLICE` closed: the command bus, store, recipe evaluation and CLI replay exist.
- `G0-CONTRACT.13` (reference skirt with numbers) and `G0-CONTRACT.10` (dialect modes) recorded.

## Non-Goals

- Grading and multiple sizes (G3), Factory Profiles and the artifact policy matrix (G4), the
  shipped UX (G5), real import-filter validation against factory products (G6), DXF *import*
  (G6 scope per §13), HPGL (G4).
- Any claim that an exporter's output is accepted by a named factory — that is G6/G7 evidence.

## Decisions

- `2026-09-29`: the offset engine and its pathology corpus are separate leaves (`.2`, `.3`)
  because the corpus is the oracle that makes the engine's error policy falsifiable; merging them
  would let an implementation grade its own homework.
- `2026-09-29`: the PDF library evaluation is a recorded decision inside `.6`, not a silent
  dependency choice — §7.5 names the candidates and asks for evidence.
